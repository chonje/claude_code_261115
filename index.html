    모든 안에 같은 월세를 넣은 값입니다. 방이 9㎡대인 C·D안은 프리미엄 월세를 받기 어렵고, 공사비는 면적 기준이라 욕실 개수 차이는 들어 있지 않습니다.

    방별 면적과 배관 거리 (선택한 배치안)

    확인이 필요한 것

    • 구리시청 건축과 다중생활시설 건축기준과 구리시 건축 조례의 방 최소 면적·복도 폭·창 기준, 용도변경 가능 여부와 주차 대수. 여기 쓴 9㎡, 1,500/1,200mm는 기본값입니다.
    • 소방서 간이스프링클러, 비상구·발코니 규격, 완강기, 내부 마감재 기준.
    • 현장 실측 네 면 외벽마다 창을 낼 수 있는지(인접 건물·대지경계), 왼쪽 벽 바깥에 발코니를 달 공간, 기둥 위치와 크기, 주출입구 폭, 층고, 배수 입상관 위치.
    • 도면과 다른 점 사진에서는 화장실 왼쪽 위(10,500 / 7,600)와 출입구 오른쪽(14,900 / 7,600)에 기둥이 보이고, 아래쪽 벽 10,500 지점 기둥은 보이지 않습니다. 점선 기둥으로 표시했습니다.
    • 화장실을 세탁실로 기존 공용 화장실이 2층 전용인지 건물 공용인지, 계단실 쪽 문을 막고 주방 쪽 벽에 문을 낼 수 있는지, 방마다 욕실이 있어도 공용 화장실이 따로 필요한지.
    • 면적 방 면적은 벽 중심선 기준이라 실제 내부 면적은 벽 두께만큼 줄어듭니다.
    배관 거리는 각 방 욕실 중심에서 배수 기준점까지 직각 경로 길이입니다. 화면의 1:100은 CSS 96dpi 가정이라 기기마다 오차가 있고, 도면 안 축척 막대는 항상 맞습니다.
