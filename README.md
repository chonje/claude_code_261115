# 수택동 504-8 2층 고시원 배치안

경기도 구리시 수택동 504-8 건물 2층(근린생활시설, 의원)을 고시원(제2종 근린생활시설 중 다중생활시설)으로 바꾸는 배치 검토 자료입니다. 검토용이며 인허가 도면이 아닙니다.

## 여는 방법

`index.html` 하나만 브라우저로 열면 됩니다(데이터가 파일 안에 들어 있어 서버가 필요 없음). 휴대폰에서는 평면도가 세로로 돌아간 상태로 열리고, 도면 위 버튼으로 가로/세로, 화면 맞춤/1:100을 바꿉니다.

## 파일

| 파일 | 내용 |
|---|---|
| `plan.json` | 평면 좌표의 유일한 원본 (mm, 벽 중심선, 원점 = 왼쪽 위) |
| `config.json` | 설계 규칙, 창 가능 벽 기본값, 배치안 매개변수, 계산기 기본값 |
| `tools/build.py` | plan + config → `layouts.json` 생성 → 검증 → `index.html`에 데이터 삽입 |
| `tools/validate.py` | 배치 검증. `--selftest`는 일부러 망가뜨린 배치를 잡아내는지 확인 |
| `layouts.json` | 생성된 배치안 A·B·C (직접 고치지 말 것) |
| `docs/plan-2f.jpeg` | 건축물현황도 2층 평면도 |

값을 바꾼 뒤에는 `python3 tools/build.py`를 실행합니다(Python 3 표준 라이브러리만 사용). 검증에 실패하면 `index.html`은 갱신되지 않습니다.

## 배치안

| | A안 (채택) | B안 | C안 | D안 |
|---|---|---|---|---|
| 성격 | 프리미엄, 방을 키움 | 중간 크기 | 위쪽 벽만 창 | 실 수 최대 |
| 구성 | 위 5실 + 왼쪽 아래 4실 | 위 7실 + 왼쪽 아래 4실 | 위 9실 | 위 9실 + 왼쪽 아래 5실 |
| 실 수 | 9 | 11 | 9 | 14 |
| 방 면적 | 12.6~18.0㎡ (평균 13.9) | 10.2~13.4㎡ (평균 11.4) | 9.1㎡ | 9.1~9.7㎡ (평균 9.3) |
| 총 배관 거리 | 95m | 117m | 97m | 140m |

- **A안**: 프리미엄 고시텔(월세 70만~80만 원 목표)용. 위쪽 5실의 벽을 기둥 간격(3,500 / 3,500 / 3,500 / 4,400 / 5,000)에 맞춰 창이 기둥에 걸리지 않습니다.
- **D안**이 14실인 근거: 복도 약 29.9㎡와 공용 최소 면적을 빼고 9㎡로 나누면 14실이 상한입니다. 방 폭이 2.1~2.2m로 좁습니다.
- 네 안 모두 복도는 폭 1,500 직선(본체 전체 길이), 주출입구 옆에 현관, 복도 왼쪽 끝 외벽에 비상구와 발코니를 둡니다.
- **기존 공용 화장실 → 세탁실** (`config.json`의 `toiletToLaundry`): 방마다 욕실이 있으므로 기존 화장실(2,300×2,600, 6.0㎡)을 세탁실로 바꾸고, 그 위 칸을 주방으로 둬서 배관을 한곳에 모았습니다. 세탁실은 주방을 거쳐 들어가고, 계단실 쪽 기존 문은 막는 것으로 가정했습니다. 원래 세탁실 자리가 비면서 휴게 공간이 12.5㎡로 커집니다. `false`로 바꾸면 화장실을 그대로 두는 배치로 돌아갑니다.

## 검증 결과

`python3 tools/validate.py` 기준 네 안 모두 통과:

- 공간끼리 겹치지 않고 평면(본체 + 확장부) 밖으로 나가지 않음
- 방 + 복도 + 공용 면적 합 184.52㎡ (내부 178.5㎡ + 세탁실로 바꾼 화장실 5.98㎡, 허용 ±1%)
- 모든 방이 복도에 문으로 접하고, 창 가능 외벽에 접함 (C안은 위쪽 벽만 켠 조건)
- 방 최소 면적 9㎡, 방 최소 폭, 복도 폭 1,500, 욕실 1,200×1,800이 방 안에 있고 문을 막지 않음
- 세탁·주방·휴게·현관이 있고 복도에 접함(세탁실은 복도에 접한 주방을 거쳐 문으로 연결), 현관이 주출입구를 포함
- 비상구가 복도 끝 외벽에 있고 주출입구에서 평면 대각선의 절반 이상 떨어짐

## 가정한 값

도면이나 법규에서 확인한 값이 아니라 이 작업에서 정한 값입니다. 모두 `config.json` / `plan.json`에서 바꿀 수 있습니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 방 최소 면적(욕실 포함) | 9㎡ | 의뢰 기본값. 구리시 조례 미확인 |
| 복도 폭 | 양쪽 1,500 / 한쪽 1,200 | 의뢰 기본값. 공용실도 "방"으로 쳐서 세 안 모두 1,500 적용(보수적) |
| 욕실 | 1,200×1,800 | 의뢰값 |
| 방 최소 폭 | 2,100 | 욕실 1,200 + 문 900. 벽 두께 미반영 |
| 문 폭 / 창 폭 | 900 / 1,200 (기둥 간섭 시 최소 600) | 설계 가정 |
| 공용 최소 면적 | 세탁 4, 주방 4.5, 휴게 5, 현관 4㎡ | 설계 가정. 법규 수치 아님 |
| 비상구 이격 | 주출입구에서 대각선의 1/2 이상 | 검증용 설계 가정. 법규 수치 아님 |
| 발코니 깊이 | 1,200 | 추정 |
| 기둥 크기 | 400×400 | 추정 (도면에 치수 없음) |
| 주출입구 위치 | x 13,300~14,300 | 추정. 사진을 재 보면 약 13,000~14,600 |
| 배수 기준점 | 기존 화장실 중심 (11,650 / 8,900) | 추정. 배관 거리는 욕실 중심에서 직각 경로 |
| 방 면적 | 벽 중심선 기준 | 실제 내부 면적은 벽 두께만큼 줄어듦 |
| 수익 계산 | 월세 75만, 가동률 80%, 운영비 35%, 평당 공사비 300만, 예비비 10%, 임차료 0(자가), 준비 기간 5개월 | 전부 가정치. 프리미엄 고시텔 기준 |
| 인근 현장 준공 | 2029년 12월 | 의뢰값(예정). 남은 개월은 여는 날 기준으로 계산 |

수익 계산식: 월 순수익 = 유효 실 수 × 월세 × 가동률 × (1 − 운영비 비율) − 건물 임차료, 총 공사비 = 배치 면적(내부 178.54㎡ + 화장실 5.98㎡ = 184.52㎡ = 55.8평) × 평당 공사비 × (1 + 예비비), 회수 개월 = 총 공사비 ÷ 월 순수익. 유효 실 수는 창 가능 벽에 접한 방만 셉니다. 공사비를 면적 기준으로 잡았으므로 욕실 개수 차이는 반영되지 않고, 모든 안에 같은 월세를 적용합니다(방이 9㎡대인 C·D안은 프리미엄 월세를 받기 어려움). 기본값에서 A안은 월 순수익 351만 원, 총 공사비 약 1억 8,400만 원, 회수 52.5개월입니다. 평당 300만 원은 검색으로 모은 프리미엄급 사례 범위(250만~350만 원)의 중간이며 견적 전 가정입니다.

## 확인 필요

### 도면과 의뢰 메모가 다른 점
- [ ] 기둥: 도면 사진에서는 (10,500 / 7,600)과 (14,900 / 7,600)에 기둥이 보이는데 메모에는 없음. 메모의 아래쪽 벽 (10,500 / 10,200) 기둥은 사진에서 보이지 않음. `plan.json`에 `uncertain`으로 넣었고 화면에는 점선 기둥으로 표시. 배치에는 영향 없음(모두 벽선 위).
- [ ] `docs/building.png`(층별 현황 캡처)가 저장소에 없어 건물 개요(4층 RC, 1층 제조업소+주차장, 3·4층 사무소)는 대조하지 못함.

### 화장실을 세탁실로 바꾸는 것
- [ ] 기존 화장실이 2층 전용 부분인지 건물 공용 부분인지 (도면상 문이 계단실 쪽으로 나 있음). 공용이면 다른 층 이용자와 건물 관리 문제가 생김
- [ ] 방마다 욕실이 있어도 관리자·방문객용 공용 화장실이 따로 필요한지 (건축과, 소방서)
- [ ] 화장실과 주방 사이 벽(y=7,600)에 문을 낼 수 있는지 (구조벽 여부, 모서리 기둥)

### 구리시청(건축과)
- [ ] 다중생활시설 건축기준(국토교통부 고시) 현행 내용과 구리시 건축 조례: 실 최소 면적, 복도 폭, 창 설치 기준과 창 크기, 실내 취사 금지 범위
- [ ] 이 건물 2층의 용도변경 가능 여부(같은 건물 내 다중생활시설 바닥면적 합계 제한, 지구단위계획 등)
- [ ] 용도변경에 따른 부설주차장 대수 (1층 주차장 현황 포함)
- [ ] 정화조 용량, 장애인 편의시설 대상 여부
- [ ] 1층 제조업소와 같은 건물에 두는 데 제한이 있는지

### 소방서
- [ ] 간이스프링클러 등 소방시설, 다중이용업 완비증명 요건
- [ ] 비상구와 발코니(또는 부속실) 규격, 완강기, 비상구 위치 기준
- [ ] 내부 마감재, 칸막이 내화·차음 기준, 실별 창 크기(피난·환기)

### 현장
- [ ] 네 면 외벽 각각에 창을 낼 수 있는지 (인접 건물, 대지경계선 이격, 기존 창 위치) → 화면의 벽 토글로 반영
- [ ] 왼쪽 벽 바깥에 발코니를 달 공간과 구조 (대지경계선, 1층 주차 동선)
- [ ] 기둥 실제 위치·크기. C·D안의 2, 7, 9번 방과 B안의 3, 7번 방은 기둥 때문에 창 폭이 1,200보다 좁아짐 (A안은 해당 없음)
- [ ] 주출입구 실제 위치와 폭, 계단실 방화문 여부
- [ ] 배수 입상관 위치와 바닥 슬래브 구배 여유(욕실 14개 배관을 바닥 올림으로 처리할 수 있는지), 급탕·전기 용량
- [ ] 층고와 보 밑 높이, 벽 두께, 방위(도면에 없음)
- [ ] 수익 가정: 70만 원대 인근 업소의 방 크기·시설·공실, 가동률, 시공사 견적(평당 단가)
- [ ] 다중생활시설은 방 안에 취사시설을 둘 수 없음. 프리미엄 구성(공용 주방·라운지 수준)을 이 제약 안에서 정해야 함
